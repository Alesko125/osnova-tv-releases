# ОСНОВА ТБ — збірки застосунку

Звідси застосунок, встановлений не з Google Play, дізнається про нову версію.

- `version.json` — остання версія: номер, адреса APK, його SHA-256 і що змінилось.
- APK лежать у [релізах](https://github.com/Alesko125/osnova-tv-releases/releases).

Вихідного коду тут немає.
